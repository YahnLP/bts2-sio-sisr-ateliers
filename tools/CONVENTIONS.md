# Conventions de rédaction du site

1. **Tout changement de contenu est validé par l'enseignant** avant publication sur `main`.
2. **Gabarit d'un atelier** (`docs/axe-x-nom/Xnn-nom/`) : `README.md` (fiche) et `01-atelier.md` (guide, exercices, grille sur 20).
3. **Exercices** : réponses attendues dans des blocs `<details markdown="1"><summary>Voir la réponse attendue</summary>`.
4. **Chiffres** : tout chiffre d'un exercice est recalculé avant d'être écrit ; tout script est exécuté avant d'être publié.
5. **Épreuves** : E5 (oral, 40 min, coefficient 4) et E6 (pratique et orale, coefficient 4), d'après l'arrêté du 8 juillet 2024 ; le modèle officiel et les grilles viennent de la circulaire nationale d'organisation.
6. **Confidentialité** : aucun mot de passe, adresse ou nom réel dans les exemples ; cas fictifs annoncés comme tels.
7. **Sécurité** : les manipulations ne se font que sur des machines de laboratoire.
8. **Titres** : pas d'emoji ; page d'accueil signée « Yahn LE PRETTRE - Formateur », sans référence à un établissement.
9. **Vérification avant commit** : `mkdocs build --strict` doit passer.
10. **Schémas** : pas de Mermaid (il dépend d'un script externe) ; les schémas sont des figures SVG intégrées à la page.
11. **Cas fictifs** : tout nom d'entreprise, de personne, d'adresse est inventé ; les adresses IP des exemples sont des adresses de documentation ou privées.
