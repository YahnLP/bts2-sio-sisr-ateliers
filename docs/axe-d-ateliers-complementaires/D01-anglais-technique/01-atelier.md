# D01 – Anglais technique : lire, écrire et dire l'essentiel

## 1. Lire un message d'erreur

Un message d'erreur est court et précis : on le **lit en entier** avant de le chercher sur Internet.

| Message | Sens | Piste |
|---|---|---|
| `Permission denied` | Droits insuffisants | Vérifier le compte et les droits |
| `Connection refused` | La machine répond, mais **aucun service n'écoute** sur ce port | Service arrêté ou mauvais port |
| `Connection timed out` | Aucune réponse | Pare-feu, route, machine éteinte |
| `No route to host` | Aucun chemin vers la destination | Passerelle, adressage |
| `Name or service not known` | Le nom ne se résout pas | DNS |
| `No space left on device` | Disque plein | Libérer de la place, vérifier les journaux |

## 3. Écrire une demande d'assistance en anglais

| Rubrique | Contenu |
|---|---|
| **Summary** | Une ligne : quoi, où |
| **Impact** | Qui est touché, depuis quand |
| **Steps to reproduce** | Ce qu'on fait pour voir l'erreur |
| **Expected / Actual** | Ce qu'on attendait / ce qu'on obtient |
| **What I tried** | Ce qui a déjà été essayé |

**Exercice 1.** Écris en anglais le ticket correspondant à : « Depuis 9 h, le serveur de fichiers refuse la connexion depuis le poste PC-07 ; message `Connection refused` ; trois personnes sont bloquées ; j'ai redémarré le poste. »

<details markdown="1">
<summary>Voir un exemple</summary>

*Summary:* File server refuses connections from PC-07. *Impact:* Three users cannot access shared files since 9:00. *Steps to reproduce:* open the shared folder from PC-07. *Expected:* the folder opens. *Actual:* error « Connection refused ». *What I tried:* restarted PC-07, no change.
</details>

## 4. Comprendre un extrait de documentation

> *Restart the service after editing the configuration file. Changes will not take effect until the service is reloaded. Do not edit this file while the service is running in production.*

**Exercice 2.** Que doit-on faire, dans quel ordre, et que ne faut-il pas faire ?

<details markdown="1">
<summary>Voir la réponse</summary>

Modifier le fichier de configuration, puis redémarrer ou recharger le service : sans cela, rien n'est pris en compte. Il ne faut pas modifier ce fichier pendant que le service tourne en production.
</details>

## 5. Présenter sa réalisation en deux minutes

**Exercice 3 (2e année).** Prépare puis dis à voix haute, en anglais, une présentation de ta réalisation : *context, need, solution, my part, result*. Cinq phrases suffisent ; fais-toi relire par ton voisin.
