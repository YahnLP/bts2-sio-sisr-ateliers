# A07 – Épreuve E6 blanche : expression de besoins, réalisation, recette

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – atelier de professionnalisation |
| **Axe** | Axe A – Portfolio et épreuves E5/E6 |
| **Durée indicative** | 3 h |
| **Compétence(s) visée(s)** | Concevoir, installer-tester-déployer, exploiter-dépanner-superviser une solution d'infrastructure (bloc 2 de l'option SISR) |
| **Prérequis** | A02 ; laboratoire avec une machine serveur virtuelle |
| **Livrable** | Une **réalisation testée** dans le temps imparti, une **procédure d'une page** et la **grille d'observation** remplie. |
| **Co-animation** | Possible avec l'enseignant de CEJM (dossier, oral). **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Analyser une **expression de besoins** en 30 minutes
2. Présenter son **analyse** et justifier ses **choix**
3. **Réaliser** la solution en 1 heure
4. Conduire la **recette** avec des tests prévus
5. Gérer son **temps** sur l'ensemble
