# A03 – Repérer et combler les compétences insuffisamment couvertes

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – atelier de professionnalisation |
| **Axe** | Axe A – Portfolio et épreuves E5/E6 |
| **Durée indicative** | 1 h 30 |
| **Compétence(s) visée(s)** | Toutes les compétences du bloc E5 |
| **Prérequis** | A01 ; tableau de synthèse commencé (1re année) |
| **Livrable** | Un **tableau de couverture** des six compétences du bloc E5 et un **plan pour combler** chaque manque. |
| **Co-animation** | Possible avec l'enseignant de CEJM (dossier, oral). **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Croiser les **réalisations** avec les **six compétences** du bloc E5
2. Distinguer **couverture réelle** et couverture déclarée
3. Trouver une **activité** pour combler une compétence manquante
4. Mettre à jour le **tableau de synthèse**
