# A02 – Choisir et défendre ses deux réalisations pour l'E6

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – atelier de professionnalisation |
| **Axe** | Axe A – Portfolio et épreuves E5/E6 |
| **Durée indicative** | 2 h |
| **Compétence(s) visée(s)** | Concevoir, installer-tester-déployer, exploiter-dépanner-superviser une solution d'infrastructure (bloc 2 de l'option SISR) |
| **Prérequis** | A01 |
| **Livrable** | Une **matrice de couverture** des deux réalisations et un **argumentaire d'une page** justifiant le choix. |
| **Co-animation** | Possible avec l'enseignant de CEJM (dossier, oral). **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Appliquer les **critères de choix** de deux réalisations
2. Remplir une **matrice de couverture** réalisation × compétence
3. Identifier la **réalisation à compléter ou remplacer**
4. Rédiger l'**argumentaire de choix**

- [ ] Citer les critères de choix d'une réalisation pour l'E6

- [ ] Repérer ce qui manque
