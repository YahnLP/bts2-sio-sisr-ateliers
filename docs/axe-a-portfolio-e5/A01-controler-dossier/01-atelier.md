# A01 – Contrôler son dossier avant la remise

## 1. Pourquoi contrôler avant la remise

Le dossier numérique est **contrôlé avant l'épreuve**. Une non-conformité coûte des points **avant même que tu aies parlé**. Les pénalités annoncées par la circulaire de la session 2026 (voir [Épreuves E5 et E6](../../ressources/epreuves-e5-e6.md)) :

| Situation | Pénalité |
|---|---|
| Portfolio **inaccessible** (E5) | **10 points** |
| **Absence de tableau de synthèse** (E5) | **2 points** |
| **Une** réalisation absente (E6) | **10 points** |
| **Les deux** réalisations absentes (E6) | **20 points** |
| Environnement non conforme à l'annexe II.E (E6) | **jusqu'à 15 points** |

## 2. La checklist

### E5 – dossier numérique

| Contrôle | Fait |
|---|---|
| Le **portfolio** est accessible **en format électronique**, sans compte ni mot de passe à demander | - [ ] |
| Le **tableau de synthèse** est au modèle de la circulaire (fichier `.xlsx`) | - [ ] |
| Pour chaque réalisation : **intitulé court**, **productions et documents**, **période**, **compétences mobilisées** | - [ ] |
| Les **six compétences** du bloc E5 sont mobilisées **par l'ensemble** des réalisations | - [ ] |
| Les **attestations de stage** ou **certificats de travail** sont présents, au modèle | - [ ] |
| Les réalisations sont faites dans un **environnement conforme à l'annexe II.E** | - [ ] |

### E6 – deux réalisations

| Contrôle | Fait |
|---|---|
| **Deux** fiches descriptives, au modèle de la circulaire | - [ ] |
| Chaque fiche indique les **modalités d'accès aux éléments techniques** | - [ ] |
| Schémas, documentation, ressources matérielles et logicielles sont **joints ou accessibles** | - [ ] |
| Les deux réalisations couvrent **ensemble** toutes les compétences du bloc 2 | - [ ] |
| Environnement **conforme** à l'annexe II.E | - [ ] |

## 3. Le test du poste vierge

C'est la seule façon de savoir si ton portfolio est vraiment accessible.

1. Utilise un **autre ordinateur** (ou une session invitée), **sans** aucun compte connecté.
2. Ouvre le portfolio **uniquement** avec le lien ou le fichier que tu remettras.
3. Ouvre **tous** les liens du portfolio : aucun ne doit demander une connexion.
4. Ouvre les pièces jointes : elles s'affichent sans logiciel particulier.
5. Note le **résultat** (date, appareil, liens en échec) et corrige.

> [!WARNING]
> Un lien qui fonctionne **depuis ton compte** peut être inaccessible pour le jury. Seul le test sans compte compte.

## 4. Exercice : auditer un dossier fictif

> *Dossier de « Candidat X » (cas fictif). Portfolio : un lien de partage d'un service en ligne qui demande de se connecter avec une adresse de courriel. Tableau de synthèse : absent, remplacé par une liste dans le portfolio. Attestations : une seule attestation de stage pour deux périodes en entreprise. Réalisation E6 n° 1 : fiche complète avec accès aux schémas. Réalisation E6 n° 2 : fiche sans indication d'accès aux éléments techniques. Les deux réalisations traitent de la même compétence de déploiement.*

**Questions**

1. Liste les **non-conformités**.
2. Pour chacune, donne la **pénalité** possible ou le risque.
3. Propose une **correction** pour chacune.

<details markdown="1">
<summary>Voir la réponse attendue</summary>

| Non-conformité | Pénalité ou risque | Correction |
|---|---|---|
| Portfolio derrière une connexion | Portfolio inaccessible : **10 points** | Rendre le lien public en lecture, ou remettre un fichier ; refaire le test du poste vierge |
| Tableau de synthèse absent | **2 points** | Remplir le modèle `.xlsx` de la circulaire |
| Une attestation pour deux périodes | Pièce manquante : risque au contrôle de conformité | Obtenir l'attestation de la seconde période |
| Réalisation n° 2 sans accès aux éléments techniques | Fiche incomplète : risque de réalisation jugée absente (**10 points**) | Ajouter les modalités d'accès |
| Deux réalisations sur la même compétence | Couverture du bloc 2 incomplète | Revoir le choix des réalisations (atelier A02) |

</details>
