# A04 – Préparer le dossier de remise : versions, accessibilité, plan B

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – atelier de professionnalisation |
| **Axe** | Axe A – Portfolio et épreuves E5/E6 |
| **Durée indicative** | 2 h |
| **Parcours** | **Cœur** – Dossier de remise : un portfolio inaccessible ou l'absence de tableau de synthèse sont pénalisés. Voir le [parcours cœur et complément](../../ressources/parcours-coeur-complement.md). |
| **Compétence(s) visée(s)** | Mettre à disposition un service ; organiser son développement professionnel |
| **Prérequis** | A01 à A03 |
| **Livrable** | Un **dossier de remise** complet, **sauvegardé** en deux exemplaires, avec un **plan B hors ligne**. |
| **Co-animation** | Possible avec l'enseignant de CEJM (dossier, oral). **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Constituer l'**arborescence** du dossier de remise
2. **Anonymiser** et contrôler les données sensibles
3. Prévoir un **plan B hors ligne**
4. Vérifier les **versions** et conserver une **copie**

## Contenu

| Document | Rôle |
|---|---|
| [Guide de l'atelier](01-atelier.md) | Méthode, exercices, modèles et grille d'évaluation |

## Déroulé conseillé

| Durée | Activité |
|---|---|
| 15 min | Ce qui est remis, ce qui ne l'est pas |
| 30 min | Arborescence et nommage |
| 25 min | Anonymisation : le contrôle final |
| 30 min | Plan B hors ligne et sauvegarde |
| 20 min | Exercice de relecture |

## Je sais faire

- [ ] Organiser un dossier avec une arborescence claire
- [ ] Contrôler l'absence de données sensibles
- [ ] Préparer une version hors ligne
- [ ] Conserver deux copies datées

<details markdown="1">
<summary>Notes pour l'enseignant</summary>

- Complète l'atelier A04 de 1re année (documenter les preuves) : ici on prépare la remise, pas la production des preuves.
- Les règles de confidentialité sont celles de la convention d'entreprise : l'élève doit demander l'accord de son tuteur.
- Atelier proposé pour la 2e année : à relire et à valider avant diffusion.
