# A04 – Préparer le dossier de remise : versions, accessibilité, plan B

## 1. Ce que contient le dossier de remise

| Pièce | Format conseillé | Remarque |
|---|---|---|
| Portfolio | page web ou PDF accessible | Testé avec le poste vierge (A01) |
| Tableau de synthèse | fichier `.xlsx` au modèle officiel | Une ligne par réalisation |
| Fiches de réalisation | PDF | Une par réalisation, au modèle |
| Éléments techniques (schémas, documentation) | PDF ou images | Accès indiqué dans la fiche |
| Attestations de stage ou certificats | PDF | Au modèle de la circulaire |

## 2. Arborescence et nommage

Un dossier **lisible** se retrouve en dix secondes :

```
dossier-candidat/
  01-portfolio/
  02-tableau-synthese/
  03-fiches-realisation/
    realisation-1/
    realisation-2/
  04-elements-techniques/
  05-attestations/
  LISEZ-MOI.txt
```

Règles de nommage :

| À faire | À éviter |
|---|---|
| `realisation-1-fiche-v3.pdf` | `Document final (2) vraiment final.pdf` |
| Date au format `AAAA-MM-JJ` | Espaces, accents et caractères spéciaux |
| Un seul fichier courant par pièce | Plusieurs versions mélangées |

## 3. Le contrôle final de confidentialité

Aucun document présenté ne doit contenir :

- un **mot de passe** réel ;
- une **adresse IP publique** ou un **nom de domaine** réel de l'entreprise ;
- le **nom d'une personne** (collègue, client, utilisateur) ;
- un **numéro de série** ou un identifiant de licence.

| Donnée | Remplacer par |
|---|---|
| Mot de passe | `********` ou une mention « identifiant de laboratoire » |
| Adresse IP publique | une adresse de documentation (`203.0.113.x`) |
| Nom d'une personne | un rôle (« technicien », « utilisateur A ») |
| Nom de l'entreprise | `entreprise-exemple` si la convention l'exige |

> [!WARNING]
> Une capture d'écran peut **cacher** des données dans un coin (barre de titre, onglets, notifications). Zoome et relis **chaque** capture.

## 4. Le plan B hors ligne

Le réseau de la salle d'examen n'est pas garanti. Prépare :

1. Une **copie complète** du dossier sur une clé USB (ou autre support autorisé) ;
2. Une version **PDF** du portfolio ;
3. Pour une démonstration, une **vidéo courte** ou des **captures** ;
4. La liste des **liens externes** et ce qu'ils contiennent.

## 5. Sauvegarder

| Règle | Application |
|---|---|
| **Deux** exemplaires | disque local et clé USB |
| **Datés** | dossier `2027-05-15` (date fictive, à adapter) |
| **Vérifiés** | ouvrir chaque fichier de la copie |
