# C04 – Tester une restauration : RPO, RTO et rapport

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – atelier de professionnalisation |
| **Axe** | Axe C – Ateliers techniques |
| **Durée indicative** | 2 h |
| **Compétence(s) visée(s)** | Assurer la continuité du service ; assurer la cybersécurité |
| **Prérequis** | Sauvegardes de 1re année |
| **Livrable** | Un **rapport de test de restauration** comparant mesures et objectifs. |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Définir **RPO** et **RTO**
2. Vérifier qu'une sauvegarde respecte le **RPO**
3. Estimer et mesurer le **temps de restauration**
4. Rédiger un **rapport de test**
5. Conclure : objectifs tenus ou non

<details markdown="1">
<summary>Notes pour l'enseignant</summary>

- Les débits et volumes sont fictifs ; durée recalculée (20 min pour 120 Go à 100 Mo/s, en unités décimales).
- Un test réel suppose un environnement isolé.
- Atelier proposé pour la 2e année : à relire et à valider avant diffusion.

</details>
