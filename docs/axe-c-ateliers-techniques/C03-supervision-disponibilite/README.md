# C03 – Superviser et calculer la disponibilité

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – atelier de professionnalisation |
| **Axe** | Axe C – Ateliers techniques |
| **Durée indicative** | 2 h |
| **Compétence(s) visée(s)** | Mettre à disposition un service ; répondre aux incidents |
| **Prérequis** | Notions de supervision de 1re année |
| **Livrable** | Une **fiche de supervision** : indicateurs, seuils, alertes et calcul de disponibilité. |
| **Co-animation** | Possible avec l'enseignant du bloc technique concerné ou le tuteur. **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Choisir des **indicateurs** utiles
2. Fixer **deux seuils** : avertissement, critique
3. Calculer une **disponibilité**
4. Traduire un pourcentage en **minutes d'indisponibilité**
5. Éviter la **fatigue d'alertes**

## Je sais faire

- [ ] Fixer un seuil d'avertissement et un seuil critique
- [ ] Calculer une disponibilité mensuelle
- [ ] Convertir 99 %, 99,5 %, 99,9 % en durée
- [ ] Limiter les alertes aux cas utiles

<details markdown="1">
<summary>Notes pour l'enseignant</summary>

- Les valeurs sont fictives. Un mois de 30 jours = 43 200 minutes.
- Les seuils sont des exemples : à adapter au service.
- Atelier proposé pour la 2e année : à relire et à valider avant diffusion.

</details>
