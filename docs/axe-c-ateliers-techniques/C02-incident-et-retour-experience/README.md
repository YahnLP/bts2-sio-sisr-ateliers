# C02 – Gérer un incident et rédiger le retour d'expérience

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – atelier de professionnalisation |
| **Axe** | Axe C – Ateliers techniques |
| **Durée indicative** | 2 h |
| **Compétence(s) visée(s)** | Répondre aux incidents et aux demandes |
| **Prérequis** | B04 (communication de crise) |
| **Livrable** | Une **fiche d'incident** et un **retour d'expérience** (REX). |
| **Co-animation** | Possible avec l'enseignant du bloc technique concerné ou le tuteur. **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Tenir la **chronologie** d'un incident
2. Calculer **durées de détection et de résolution**
3. Chercher la **cause racine** (méthode des cinq pourquoi)
4. Écrire des **actions préventives**
5. Rédiger un REX sans chercher un coupable

## Je sais faire

- [ ] Dresser une chronologie datée
- [ ] Calculer une durée d'incident
- [ ] Remonter à la cause racine
- [ ] Proposer une action préventive mesurable
