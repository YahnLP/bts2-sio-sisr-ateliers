# C01 – Auditer un parc et planifier la remédiation

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – atelier de professionnalisation |
| **Axe** | Axe C – Ateliers techniques |
| **Durée indicative** | 2 h |
| **Parcours** | **Cœur** – Audit de parc : seul atelier sur la compétence « gérer le patrimoine informatique » en 2e année. Voir le [parcours cœur et complément](../../ressources/parcours-coeur-complement.md). |
| **Compétence(s) visée(s)** | Gérer le patrimoine informatique ; assurer la cybersécurité |
| **Prérequis** | Inventaire de 1re année |
| **Livrable** | Un **rapport d'audit** : inventaire, écarts, priorités et plan de remédiation. |
| **Co-animation** | Possible avec l'enseignant du bloc technique concerné ou le tuteur. **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Définir un **référentiel** de conformité
2. Mesurer les **écarts**
3. **Prioriser** par criticité
4. Écrire un **plan de remédiation** daté
5. Présenter un **taux de conformité**

## Contenu

## Déroulé conseillé

| Durée | Activité |
|---|---|
| 15 min | Référentiel |
| 30 min | Relevé des écarts |
| 25 min | Priorisation |
| 35 min | Plan de remédiation |
| 15 min | Restitution |

## Je sais faire

- [ ] Écrire un référentiel vérifiable
- [ ] Calculer un taux de conformité
- [ ] Prioriser des écarts
- [ ] Rédiger un plan d'actions avec échéances
