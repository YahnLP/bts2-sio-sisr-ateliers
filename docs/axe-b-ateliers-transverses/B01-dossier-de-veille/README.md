# B01 – Du suivi de veille au dossier de veille défendable

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – atelier de professionnalisation |
| **Axe** | Axe B – Ateliers transverses |
| **Durée indicative** | 1 h 30 |
| **Parcours** | **Cœur** – Dossier de veille : seul atelier de 2e année sur cette pratique (organiser son développement professionnel). Voir le [parcours cœur et complément](../../ressources/parcours-coeur-complement.md). |
| **Compétence(s) visée(s)** | Organiser son développement professionnel |
| **Prérequis** | Une veille commencée (1re année) |
| **Livrable** | Un **dossier de veille** : sujet, sources évaluées, six fiches, une synthèse et trois phrases pour l'oral. |
| **Co-animation** | Possible selon le thème (CEJM, anglais, enseignant du bloc concerné). **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Formuler une **question de veille** précise
2. **Évaluer la fiabilité** de ses sources
3. Rédiger une **fiche de veille** utile
4. Écrire une **synthèse** qui montre l'impact sur son activité
5. **Défendre** sa veille à l'oral en trois phrases

## Je sais faire

- [ ] Formuler une question de veille
- [ ] Classer des sources par fiabilité
- [ ] Rédiger une fiche en dix lignes
- [ ] Dire ce que ma veille a changé dans mon travail
