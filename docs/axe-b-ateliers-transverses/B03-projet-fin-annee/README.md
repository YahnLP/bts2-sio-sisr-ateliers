# B03 – Conduire et clore le projet de fin d'année

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – atelier de professionnalisation |
| **Axe** | Axe B – Ateliers transverses |
| **Durée indicative** | 2 h |
| **Parcours** | **Cœur** – Projet de fin d'année : seul atelier sur la compétence « travailler en mode projet ». Voir le [parcours cœur et complément](../../ressources/parcours-coeur-complement.md). |
| **Compétence(s) visée(s)** | Travailler en mode projet |
| **Prérequis** | B03 de 1re année (mini-projet) |
| **Livrable** | Un **dossier de projet** : cadrage, planning, risques, suivi et bilan. |
| **Co-animation** | Possible selon le thème (CEJM, anglais, enseignant du bloc concerné). **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Cadrer un projet avec un **objectif**, un **périmètre** et des **livrables**
2. Construire un **planning** avec dépendances
3. Évaluer les **risques**
4. Suivre l'**avancement** (prévu / réalisé)
5. Rédiger le **bilan** de clôture

## Je sais faire

- [ ] Écrire un objectif mesurable
- [ ] Calculer la durée minimale d'un projet
- [ ] Noter les risques par probabilité et impact
- [ ] Rédiger un bilan avec retour d'expérience
