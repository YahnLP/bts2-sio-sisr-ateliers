# B04 – Communication de crise : informer sans paniquer

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – atelier de professionnalisation |
| **Axe** | Axe B – Ateliers transverses |
| **Durée indicative** | 1 h 30 |
| **Parcours** | **Cœur** – Communication de crise : prérequis de C02. Voir le [parcours cœur et complément](../../ressources/parcours-coeur-complement.md). |
| **Compétence(s) visée(s)** | Répondre aux incidents et aux demandes ; mettre à disposition un service |
| **Prérequis** | B04 de 1re année (communication professionnelle) |
| **Livrable** | Trois **messages types** (alerte, point d'étape, clôture) pour un incident fictif. |
| **Co-animation** | Possible selon le thème (CEJM, anglais, enseignant du bloc concerné). **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Adapter le message à son **public**
2. Rédiger un **premier message** utile en moins de cinq lignes
3. Annoncer la **prochaine information** à une heure précise
4. Rédiger un **message de clôture**
5. Éviter les **erreurs** qui aggravent la crise

## Je sais faire

- [ ] Écrire un premier message en cinq lignes
- [ ] Annoncer l'heure du prochain point
- [ ] Distinguer message direction et message utilisateurs
- [ ] Clore un incident par un message complet
