# Mode d'emploi

Ces ateliers de 2e année **prolongent** ceux de la 1re année : on suppose que le portfolio existe et que les premières fiches de réalisation sont rédigées.

## Ordre conseillé

1. **A01** (contrôle du dossier) en début de 2e année, pour savoir ce qui manque.
2. **A02** et **A03** ensuite : fixer les deux réalisations de l'E6 et combler les compétences non couvertes.
3. Les ateliers **B** et **C** tout au long de l'année, selon les besoins de l'entreprise et du calendrier.
4. **A04** quand le dossier est stabilisé, avant la date de remise.
5. **A05**, **A06** et **A07** dans les semaines précédant les épreuves, de préférence en binôme.

## Principes

- **Contrôler avant de produire** : chaque atelier de l'axe A commence par vérifier un existant.
- **Dire « je »** : le jury cherche ta contribution personnelle.
- **Prouver** : captures, journaux de tests, schémas, procédures.
- **Protéger les données** : aucun mot de passe réel, aucune adresse réelle, aucun nom de personne dans un document présenté (atelier A04).
- **Chronométrer** : les épreuves sont à durée fixe ; on s'entraîne avec un chronomètre.

## Sécurité

Les manipulations techniques se font **uniquement** sur les machines de laboratoire ou sur des systèmes dont tu as l'**autorisation écrite** d'utiliser.
